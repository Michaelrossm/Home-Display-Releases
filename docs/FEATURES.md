# App/system split

## System
Desktop/launcher, status bar, network, mDNS, time/NTP, settings, display rotation/brightness, idle/screensaver, storage, OTA, notifications, media-session bridge.

## Apps
- Fritz Radio: FSAPI/UNDOK control and now-playing; old discovery/favorites engines retained for next UI pages.
- Wetter: Open-Meteo/DWD ICON logic from old firmware.
- Stromtracker: native `/api/v1/status`, Shelly RPC fallback and history API from old firmware.
- Settings: system screen; future tabs for WLAN/LAN, display, SD, OTA and app management.

## Later
Calendar/family, Goliath intercom, local ESP-SR voice control, separately installable app packages.
